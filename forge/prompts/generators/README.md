# Prompt Generators

This is the canonical location for Forge-owned Runtime Prompt Generators.
Generators transform an approved Engineering Intent and declared versioned
context into a transient Runtime Prompt. Increment 1.9 provides only the
abstract deterministic generator contract; no provider-specific generator is
stored here yet.

The first concrete generator remains a later separately governed capability and
must target the Codex CLI without changing Engineering Intent semantics.
