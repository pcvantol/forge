# Forge Roadmap

## Bootstrap Phase A — Complete

Bootstrap Phase A is complete. It delivered the local, deterministic
foundation from increments 0.1 through 0.8 and the subsequent loader,
proposal-generator, and prompt-artifact repairs. The closure record is
[Bootstrap Milestone A Report](../reports/bootstrap-milestone-a.md).

## Phase B — Self Engineering

The next phase is **Self Engineering**, beginning with **Forge Phase B —
Increment 1.0**. It is a planned transition, not an implemented capability.
Each increment remains subject to a separate bounded objective and human
approval.

### Intended sequence

1. Define durable, local Engineering Intent contracts, lifecycle, and authoring
   context from repository knowledge.
2. Define the governed Runtime Provider boundary and provider-specific Runtime
   Prompt derivation from Engineering Action.
3. Define the Engineering Mission model as the highest operational grouping
   artifact and reconcile Engineering Action as the smallest executable unit.
4. Implement the Bootstrap Mission Scheduler that releases Engineering Actions
   within their Mission and Intent context.
5. Reconstruct and migrate the Engineering Platform 1.5 bootstrap transport
   only after Forge owns that provider boundary.
6. Propose separately governed execution and evidence capabilities.

### Delivered after the intended sequence

Phase B — Increment 2.1 establishes the Execution Host Contract as the
replaceable execution boundary. Engineering Platform 1.5 remains its reference
implementation; a later increment may document that reference without copying
or generalizing its implementation.

No Phase B item implements persistence, a Runtime Provider, a Mission Runtime,
a queue, Studio, repository operation, or execution without a separately
authorized increment.
