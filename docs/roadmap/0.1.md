# Forge 0.1 Roadmap

## Bootstrap foundation

Forge 0.1 established the original workspace foundation. Forge 0.2 now
separates Workspace, Repository, Repository Catalog, Knowledge Source,
Capability, Engineering Mode, and Governance Profile contracts.

## Current direction

Forge 0.8 establishes Engineering Intent as the canonical, model-independent
engineering artefact. Future work may define a durable intent contract,
bootstrap-prompt migration, or a governed Runtime Provider boundary only by a
separate bounded decision.

## Direction after 0.1

1. Durable, local Engineering Intent contracts and validation.
2. Bootstrap prompt reconstruction and migration.
3. Governed Runtime Provider representations derived from Engineering Intent.
4. Explicit, separately governed execution capability proposals.

The sequence is directional, not an authorization to build subsequent items
without a bounded objective and human approval.
