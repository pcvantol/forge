# Forge 0.1 Roadmap

## Bootstrap foundation

Forge 0.1 established the original workspace foundation. Forge 0.2 now
separates Workspace, Repository, Repository Catalog, Knowledge Source,
Capability, Engineering Mode, and Governance Profile contracts.

## Recommended next increment

Implement a local, read-only Foundation Model loader and validator. It should
resolve the 0.2 schemas and model invariants, report actionable local
validation errors, and make no repository or network mutations.

## Direction after 0.1

1. Local workspace loader and schema validation.
2. Read-only repository inventory verification against declared local paths.
3. Human-approved engineering plan artifacts with source traceability.
4. Explicit, separately governed execution capability proposals.

The sequence is directional, not an authorization to build subsequent items
without a bounded objective and human approval.
