# Forge 0.1 Roadmap

## Delivered foundation

Forge 0.1 establishes the Workspace Foundation: versioned workspace metadata,
repository catalog entries, canonical repository references, and fixed
prototype/solo/local governance constraints.

## Recommended next increment

Implement a local, read-only Workspace Foundation loader and validator. It
should accept a path to a workspace document, validate it against the 0.1
schema, report actionable local validation errors, and make no repository or
network mutations.

## Direction after 0.1

1. Local workspace loader and schema validation.
2. Read-only repository inventory verification against declared local paths.
3. Human-approved engineering plan artifacts with source traceability.
4. Explicit, separately governed execution capability proposals.

The sequence is directional, not an authorization to build subsequent items
without a bounded objective and human approval.
