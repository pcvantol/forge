## Durable dispatch and publication

Original request, EP request bytes/digest, original Forge grant and private
pairing digest are durable before any effect POST. Under the owning boundary
one CREATE sendclaim is persisted before transport. An original intent with
no sendclaim can recover its first explicit dispatch after a healthy original
GET404. Once a sendclaim exists, all identical submissions first recover by
original GET; even GET404 after an uncertain send never causes another create.
Changed input under the same operation ID conflicts. No unbounded retry.

Explicit resume first verifies the owning original admitted EP operation and
current original authority. GET/refresh never resumes. Attempt CAS fences late
responses and late sends; older source_updated_at cannot overwrite newer
observations. EP remains the source of effect truth; stored receipts retain
original evidence and are not an independent execution database.

Authority locks cover private state and current canonical checks, never network
waits. Finite direct loopback transport has no proxy, redirects or ambient auth.
A current-authority callback runs after connect immediately before sending;
absolute deadline checks and a socket watchdog bound send and response success.
Protected publication rechecks actual peer access and current own scope/epoch
without holding own authority across the peer request. Missing/corrupt initialized
stores or absent original peer evidence fail closed, never healthy empty history
or cached COMPLETE. Revocation/expiry never triggers rollback, delete, force,
credential replacement or rewriting original evidence.
