## Durability and publication

Original immutable intent is durably sealed before decision effects. Changed
same-ID bytes/actor/grant/context conflict; exact explicit replay returns the
same decision. Append-only decisions use original revision/predecessor CAS.
Lost success recovers only original intent GET. A restart reads the same record,
never issues EP POST or creates a second preview. Missing/corrupt initialized
stores fail closed. Every protected read/decision/publication rechecks current
human, role, original source grant, pairing, original EP GET, exact subject and
history revision. No own source/authority lock spans EP or client socket wait.
Revoked/expired old decisions remain history but cease to count as current
approvals. Only both current positive roles yield CONTENT_APPROVED_ONLY.
Already published bytes cannot be withdrawn; no distributed atomic revoke is
claimed. No repository write, effect plan/approval, registration, READY,
Action or Mission is authorized.
